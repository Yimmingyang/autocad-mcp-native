# AutoCAD / .NET Compatibility Matrix

This table separates **upstream runtime/API compatibility** from this project's **tested plug-in support**.

| AutoCAD release | Autodesk managed runtime/API family | Plug-in build in this repository | Project status |
|---|---|---:|---|
| 2020 | .NET Framework 4.7 | Builds from local API candidate | Host load/connection not yet verified |
| 2021–2024 | .NET Framework 4.8 | Builds from local API candidate | Host load/connection not yet verified |
| 2025 .NET 8 builds | .NET 8 | Builds from local API candidate | Local AutoCAD 2025 R25.0.58.0.0 install and live `get_bridge_status` connection verified |
| AutoCAD 2025 Update 1.4+ | .NET 10 | Selects .NET 10 from `acdbmgd.runtimeconfig.json` | No .NET 10 AutoCAD host available for compile/load verification |
| 2026 through Update 1.1 | .NET 8 | Selects .NET 8 from `acdbmgd.runtimeconfig.json` | No host available for compile/load verification |
| 2026 Update 1.2+ | .NET 10 | Selects .NET 10 from `acdbmgd.runtimeconfig.json` | No host available for compile/load verification |
| 2027 | .NET 10 | Selects .NET 10 from `acdbmgd.runtimeconfig.json` | Installer target added; no AutoCAD 2027 host available for compile/load verification |

Autodesk states that .NET-managed applications may need migration/recompilation between releases. The target framework alone is not enough: each plug-in must also compile against that AutoCAD release's managed API assemblies and be smoke-tested inside the actual product. The installer compiles against local API assemblies and creates a release-specific bundle; it must not reuse a prebuilt 2025 DLL for other releases. AutoCAD 2026's bundle series is R25.1 and AutoCAD 2027's is R26.0.

Development note: `plugin/AutoCadMcpPlugin.Legacy.csproj` selects `net47` for 2020, `net48` for 2021–2024, .NET 8/10 based on 2025–2026 runtimeconfig, and .NET 10 for 2027. `scripts/Build-AutoCADPlugin.ps1` generates a matching Bundle. AutoCAD 2025 R25.0.58.0.0 has passed local API compilation, installation, server setup, and live pipe status response. No other AutoCAD host is installed in the current validation environment, so remaining target builds and host-load/pipe tests are pending.
