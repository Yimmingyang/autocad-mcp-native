# AutoCAD / .NET Compatibility Matrix

This table separates **upstream runtime/API compatibility** from this project's **tested plug-in support**.

| AutoCAD release | Autodesk managed runtime/API family | Plug-in build in this repository | Project status |
|---|---|---:|---|
| 2020 | .NET Framework 4.7 | No | Not supported by this binary |
| 2021–2024 | .NET Framework 4.8 | No | Not supported by this binary |
| 2025 through Update 1.3 | .NET 8 | Current bundle targets R25.0 | Validated on the local AutoCAD 2025 R25.0 host; report exact update/build when testing |
| 2025 Update 1.4+ | .NET 10 | No distinct verified build in this repository | Not claimed supported |
| 2026 through Update 1.1 | .NET 8 | No | Not claimed supported |
| 2026 Update 1.2+ | .NET 10 | No | Not claimed supported |

Autodesk states that .NET-managed applications may need migration/recompilation between releases. The target framework alone is not enough: each plug-in must also compile against that AutoCAD release's managed API assemblies and be smoke-tested inside the actual product. This project currently sets `SeriesMin=R25.0`; never manually copy the 2025 DLL into 2020–2024.
