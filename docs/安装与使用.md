# 安装与使用（Windows）

## 前置条件

- Windows x64、AutoCAD 2025 (R25.0)、Node.js 20 LTS 或更高版本。
- 下载/克隆到稳定路径，建议 `C:\Tools\autocad-mcp-native`。
- 退出 AutoCAD 后再安装或更新插件。

## 安装步骤

```powershell
git clone https://github.com/yanmiong/autocad-mcp-native.git
cd autocad-mcp-native
npm ci
npm test
npm run check
.\release\Install-AutoCadMcp.ps1
```

脚本检查 bundle 内容和自动加载字段，将插件复制到 `%APPDATA%\Autodesk\ApplicationPlugins\AutoCadMcp.bundle`；若目标已存在会备份旧目录，安装失败时尝试恢复。执行策略阻止脚本时可用：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\release\Install-AutoCadMcp.ps1
```

## 配置 Codex

编辑 `%USERPROFILE%\.codex\config.toml`，保留已有内容并添加：

```toml
[mcp_servers.autocad_2025]
command = "node"
args = ["C:\\Tools\\autocad-mcp-native\\src\\index.js"]
startup_timeout_sec = 30
tool_timeout_sec = 180
```

替换成真实路径后保存并重启 Codex。该服务通过本机 stdio / named pipe 运行，不提供 OAuth；界面提示“身份验证不支持”不代表桥接已断开。

## 连接和首次使用

1. 启动 AutoCAD 2025，并打开或新建 DWG。
2. 在 Codex 中先调用 `get_bridge_status`，确认 `version=0.5.0`、`acadVersion=25.x`、文档数正确。
3. 只读调用 `drawing_summary`、`list_layers`、`inspect_drawing_geometry`。
4. 编辑前另存副本；复杂操作先用 `preview_drawing_plan`，确认后调用 `apply_drawing_plan`。
5. 插件加载后，如需重启监听器，可在 AutoCAD 命令行输入 `ACMCPSTART`。

## 更新

备份 Codex 配置与 bundle；退出 AutoCAD；拉取源码更新；重新运行 `npm ci`、测试和安装脚本；重启 AutoCAD/Codex 并执行只读检查。不要在 AutoCAD 正运行时覆盖 DLL。

## 卸载

退出 AutoCAD 和 Codex；从 `config.toml` 删除 `[mcp_servers.autocad_2025]` 区块；移出/删除 `%APPDATA%\Autodesk\ApplicationPlugins\AutoCadMcp.bundle`。需要恢复旧插件时，将安装脚本保留的 `.backup-*` 目录还原为 bundle。

## 兼容范围

当前包声明 Autodesk Bundle `SeriesMin=R25.0`，目标 AutoCAD 2025。2020–2024 与 2026 的对应二进制和运行时尚未在此发行包中提供或验证。
