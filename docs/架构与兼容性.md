# 架构与版本支持

## 架构

- `src/index.js`：Node.js MCP stdio server，校验 MCP 参数并转发操作。
- `src/pipe-client.js`：通过 JSON Lines 与 AutoCAD Windows named pipe 通讯，包含 request ID、超时和避免重放机制。
- `plugin/Entry.cs`：AutoCAD 进程内 .NET 扩展，通过托管 API 读写图纸。
- `release/AutoCadMcp.bundle`：Autodesk 插件包，含自动加载清单、程序集和运行时配置。

客户端启动 MCP server 不等于 AutoCAD 插件已经加载。两者都正常才有端到端连接。

## 当前支持范围

Bundle 声明 `SeriesMin=R25.0`，实测目标为 AutoCAD 2025。AutoCAD 2020–2024 和 2026 的托管 API/.NET 运行时不同，需分别构建和实机验证；当前 .NET 8 DLL 不是通用 2020+ 插件。

未来安装器应按检测出的产品选包，验证下载 SHA-256，暂存安装并保留回滚，不覆盖无关客户端配置，最后用管道握手验证。无法匹配到经过测试的版本包时，应显示“不支持该版本”。

## 信任边界

MCP 使用本地 stdio，AutoCAD 桥使用本机命名管道；此项目不提供 TCP 监听。只从可信来源安装插件并遵从 AutoCAD 安全加载策略。图纸文字、路径和工具返回内容均按不可信数据处理。
