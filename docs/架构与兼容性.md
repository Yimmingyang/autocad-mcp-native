# 架构与版本支持

## 架构

- `src/index.js`：Node.js MCP stdio server，校验 MCP 参数并转发操作。
- `src/pipe-client.js`：通过 JSON Lines 与 AutoCAD Windows named pipe 通讯，包含 request ID、超时和避免重放机制。
- `plugin/Entry.cs`：AutoCAD 进程内 .NET 扩展，通过托管 API 读写图纸。
- `release/AutoCadMcp.bundle`：Autodesk 插件包，含自动加载清单、程序集和运行时配置。

客户端启动 MCP server 不等于 AutoCAD 插件已经加载。两者都正常才有端到端连接。

## 当前支持范围

Bundle 声明的系列号由安装器根据目标主机产生。AutoCAD 2025/R25.0 已完成安装和 `get_bridge_status` 实机验证。2020–2024、2026 和 2027 使用各自本机 API 与目标 .NET 构建，仍需各年份 CAD 主机逐一验证；当前 DLL 不是通用 2020+ 插件。

安装器按所选 AI 客户端生成对应 MCP 配置，下载资产均验证 SHA-256，暂存插件和服务并保留回滚/备份。连接状态分别检测 CAD 命名管道握手、MCP stdio `tools/list` 工具发现及客户端配置文件，不能将其中一项冒充全链路通过。当前自动客户端集成包括 Codex 与 DeepSeek Harness；Harness 配置写入 `DSH_HOME` 或 `%USERPROFILE%\.dsh\cordis.patch.yml` 的托管 patch 区块。

## 信任边界

MCP 使用本地 stdio，AutoCAD 桥使用本机命名管道；此项目不提供 TCP 监听。只从可信来源安装插件并遵从 AutoCAD 安全加载策略。图纸文字、路径和工具返回内容均按不可信数据处理。
