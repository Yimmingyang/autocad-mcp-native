# Windows 安装器使用说明

## 当前范围

安装器扫描注册表/安装信息发现 AutoCAD 2020–2026，读取 `acad.exe` 产品构建号并显示系列号。**目前只有 AutoCAD 2025 / R25.0 / ProductVersion 25.0.* 的插件包已经纳入仓库并验证**。AutoCAD 2025 的更新构建、2026 和其他版本没有单独验证包，安装操作会停止；不会把 R25 插件错误安装到 R23/R24/R26 主机。由于 Autodesk 的 .NET 10 过渡更新可能改变运行时，安装器仅放行已测的 `25.0.*` 产品构建，其他 2025 构建也保守阻止。`ProductVersion` 与具体 AutoCAD Update 的对应关系尚未校准。

## 运行

从 GitHub Releases 下载 `AutoCadMcpInstaller.exe` 并运行。安装器无需单独安装 .NET Runtime。点“重新检测”，仅选择 AutoCAD 2025 build `25.0.*`，确保 CAD 已退出，再点“安装/修复”。安装器从项目 Release 拉取 `autocad-mcp-r25.0.zip`，对照 GitHub Release 提供的 SHA-256 digest 检查下载包、验证 bundle SeriesMin 后，备份旧文件并安装到：

```text
%APPDATA%\Autodesk\ApplicationPlugins\AutoCadMcp.bundle
```

安装器从 nodejs.org LTS 索引下载便携 Node.js（校验官方 SHA-256），部署 MCP 服务并运行 `npm ci`，备份和更新 `%USERPROFILE%\.codex\config.toml` 的 `autocad_native` 项。重启 Codex 和 AutoCAD 后，点“测试 MCP 连接”；该按钮会实际调用 `get_bridge_status` 并检查 CAD 响应。其他 MCP 客户端需自行配置。

## 构建

Windows x64、.NET 8 SDK：

```powershell
dotnet publish installer/AutoCadMcpInstaller.csproj -c Release -o installer/publish
```

输出 `installer/publish/AutoCadMcpInstaller.exe`。不要在无法验证来源/哈希的情况下改为执行任意下载脚本。

## 版本支持路线

每个 AutoCAD 主版本都必须分别针对 Autodesk API DLL 和该主机使用的 .NET 运行时构建并在实际 AutoCAD 进程中启动验证。仅增加注册表检测或修改 bundle 的 `SeriesMin` 不会产生兼容插件。要开放 2020–2024、2026 安装选项，维护者需在对应版本 SDK/API 环境产生独立构建、测试套件和 release asset，并补齐下载映射；发布前安装器仍以阻止误装为准。
