# Windows 安装器使用说明

## 当前范围

安装器可检测 Windows 注册表登记的 AutoCAD 2020–2026 安装，并显示版本与系列号。**目前只有 AutoCAD 2025 / R25.0 的插件包已经纳入仓库并验证**。其他版本的界面状态会明确显示“对应构建尚未发布”，且安装操作会停止；不会把 R25 插件错误安装到 R23/R24/R26 主机。

## 运行

从 GitHub Releases 下载 `AutoCadMcpInstaller.exe` 并运行。安装器无需单独安装 .NET Runtime。点“重新检测”，选择 AutoCAD 2025，确保 CAD 已退出，再点“安装/修复”。安装器从项目 Release 拉取 `autocad-mcp-r25.0.zip`，对照 GitHub Release 提供的 SHA-256 digest 检查下载包，然后备份已存在的 bundle 并原子替换到：

```text
%APPDATA%\Autodesk\ApplicationPlugins\AutoCadMcp.bundle
```

安装完成后打开 AutoCAD。它不会修改用户 MCP 客户端配置；根据[安装与使用](安装与使用.md)配置 Codex/MCP 客户端，重启客户端，再调用 `get_bridge_status` 检查真实连接。安装器显示“已安装”只确认本地文件已复制，**不代表 CAD 插件已加载或 MCP 已连通**。

## 构建

Windows x64、.NET 8 SDK：

```powershell
dotnet publish installer/AutoCadMcpInstaller.csproj -c Release -o installer/publish
```

输出 `installer/publish/AutoCadMcpInstaller.exe`。不要在无法验证来源/哈希的情况下改为执行任意下载脚本。

## 版本支持路线

每个 AutoCAD 主版本都必须分别针对 Autodesk API DLL 和该主机使用的 .NET 运行时构建并在实际 AutoCAD 进程中启动验证。仅增加注册表检测或修改 bundle 的 `SeriesMin` 不会产生兼容插件。要开放 2020–2024、2026 安装选项，维护者需在对应版本 SDK/API 环境产生独立构建、测试套件和 release asset，并补齐下载映射；发布前安装器仍以阻止误装为准。
