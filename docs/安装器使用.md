# Windows 安装器使用说明

## 当前范围

安装器扫描注册表/安装信息发现 AutoCAD 2020–2026，读取 `acad.exe` 产品构建号并显示系列号。安装时，安装器从最新 GitHub Release 的 tag 源码生成压缩包，按本机 AutoCAD API DLL 编译插件，生成与系列号匹配的 Bundle；AutoCAD 2020 使用 .NET Framework 4.7、2021–2024 使用 .NET Framework 4.8，AutoCAD 2025/2026 从 `acdbmgd.runtimeconfig.json` 识别 .NET 8 或 10。AutoCAD 2026 的系列号是 `R25.1`。

当前验证证据：本机 AutoCAD 2025 / `R25.0.58.0.0` 使用其 API DLL 成功编译并生成 `R25.0` Bundle；全部旧版及 2026 目标仍需目标 AutoCAD 实机加载、连接测试。安装成功的状态只证明安装和 MCP 配置步骤完成；需打开对应 AutoCAD 并通过连接测试取得 CAD 对插件的实际响应。

## 运行

从 GitHub Releases 下载 `AutoCadMcpInstaller.exe` 并运行。安装器无需预装 .NET Runtime；如没有匹配的 SDK，它会从 Microsoft 官方发行清单下载对应 SDK 并校验 SHA-512。选择要安装的 AutoCAD，确保 CAD 已退出，再点“安装/修复”。安装器通过 GitHub Releases 的最新版本跳转和固定资产下载获取源码与服务包，对照随包发布的 SHA-256 sidecar 校验；再按本机 API 编译，核对生成的 bundle 系列号后，备份旧文件并安装到：

```text
%APPDATA%\Autodesk\ApplicationPlugins\AutoCadMcp.bundle
```

安装器从 nodejs.org LTS 索引下载便携 Node.js（校验官方 SHA-256），部署 MCP 服务并运行 `npm ci`，备份和更新 `%USERPROFILE%\.codex\config.toml` 的 `autocad_native` 项。重启 Codex 和 AutoCAD 后，点“测试 MCP 连接”；该按钮会实际调用 `get_bridge_status` 并检查 CAD 响应。其他 MCP 客户端需自行配置。

## 构建

Windows x64、.NET 8 SDK：

```powershell
dotnet publish installer/AutoCadMcpInstaller.csproj -c Release -o installer/publish
```

输出 `installer/publish/AutoCadMcpInstaller.exe`。不要在无法验证来源/哈希的情况下改为执行任意下载脚本。

## 版本验证状态

安装器会按每台电脑上的 AutoCAD API 重新编译，所以不会把其它 CAD 版本的托管 API DLL 或预编译插件复制过去。构建失败会中止安装。仍需要维护者对 AutoCAD 2020、2021、2022、2023、2024、2025 .NET 10 更新版、2026 .NET 8 和 .NET 10 更新版分别做加载与 `get_bridge_status` 实测；这些目标的“可构建”不等于“实机已验证”。
