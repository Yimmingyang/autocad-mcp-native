# 故障排查

## MCP 已启用但工具未显示

- 确认 `config.toml` 中区块、命令和 `src/index.js` 绝对路径正确。
- 确认 `node --version`、`npm ci`、`npm test` 与 `npm run check` 成功。
- 重启 Codex 以重新加载 MCP 配置。身份验证不支持是预期状态：本服务使用本机 stdio，不使用 OAuth。

## Pipe unavailable / `get_bridge_status` 超时

- 确认 AutoCAD 已启动且至少打开一张图纸。
- 检查 `%APPDATA%\Autodesk\ApplicationPlugins\AutoCadMcp.bundle\PackageContents.xml`，确认 `SeriesMin=R25.0`。
- 在 AutoCAD 命令行输入 `ACMCPSTART` 后重试。
- AutoCAD 如出现安全加载提示，核验插件来源并遵循组织策略；不要把全局 `SECURELOAD=0` 当作通用解法。
- 如果写操作已发送但客户端超时，先检查图纸状态，再决定是否重试，避免重复编辑。

## `No active AutoCAD drawing`

在 AutoCAD 中打开或新建一张 DWG。

## 命令卡住 / `eInvalidInput`

优先调用 MCP 原生工具；此版本不提供任意脚本/LISP 执行。必要时调用 `cancel_command` 清除等待的命令提示，并重新检查图纸状态。

## 插件加载或运行时错误

确认 AutoCAD 是 Windows x64 2025/R25.0；当前包的插件目标 .NET 8。记录 AutoCAD 完整版本和更新号、MCP 客户端、错误全文。不要从其他 AutoCAD 版本复制 `acmgd.dll`、`acdbmgd.dll` 或 `accoremgd.dll` 到 bundle。

## 公开问题报告注意事项

只提交脱敏版本号、日志和最小复现步骤；不要上传客户图纸、凭据、完整用户目录路径或个人截图。
